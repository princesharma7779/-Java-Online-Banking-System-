# Online Banking System

## 📌 Project Overview
Online Banking System is a web-based banking application developed using Core Java, Servlet, JDBC, MySQL, HTML, and CSS.  
This project allows users to register, login, deposit money, and transfer funds securely.

---

## 🚀 Features
- User Registration
- User Login Authentication
- Deposit Money
- Money Transfer
- Session Management
- JDBC Database Connectivity
- Transaction Management

---

## 🛠 Technologies Used
- Core Java
- Servlet
- JDBC
- MySQL
- HTML
- CSS
- Apache Tomcat

---

## 🗄 Database
### Database Name
```sql
banking_system

### Tables
- users
- transactions

---

## ▶️ How to Run Project

1. Install MySQL and Apache Tomcat
2. Create database in MySQL
3. Import SQL tables
4. Open project in Eclipse/IntelliJ
5. Configure Tomcat Server
6. Run the project
7. Open browser and run:
   
http://localhost:8080/OnlineBankingSystem
```
Example:
- Registration Page
- Login Page
- Deposit Page
- Transfer Page
